HOW TO USE THIS SCREEN

The picture

Four boxes. CHAOS MONKEY is us: we attack the LEGACY SYSTEMS of an old bank on purpose (a website, a Unix file server, a 1987 mainframe). THE BEES are AI agents that watch those systems and fix what broke, live. THE GARDENER turns a failure that keeps coming back into new, tested code. Arrows light up as it happens: red = an attack lands, green = a fix is verified, orange = new code deployed. Everything you see is read live from MongoDB.

Looking inside

Click a box · keys 1 2 3 4Zoom in: 1 Chaos Monkey (every attack and the defence that answered it) · 2 Legacy systems (the cascade, what each system claims, the lie) · 3 the Bees (each agent, the system it is working on, its moves on a timeline) · 4 the Gardener (the code fix, step by step).

Buttons (top right, small)

START · SStarts Night 1: the attack begins. After a night it reads START OVER (wipes everything, runs Night 1 again).
KILL A WORKER · KReally kills (SIGKILL) the worker agent that is in the middle of a fix. Glows red when one is mid-job. A nurse agent takes over its job from the saved progress in MongoDB.
KILL THE QUEEN · QKills the coordinator; the backup queen notices the silence and takes over.
NEXT NIGHT · NNight 2 = the same attack again: the Bees remember it and fix it faster. Night 3 = the attack after the Gardener's upgrade: nothing breaks.
RESET + · RRESET THIS NIGHT keeps what the Bees learned. FULL RESET wipes everything back to before Night 1. Also: run any night, DETAILS (MongoDB, memory search, numbers), the classic war room.
APPROVE / DENYRisky steps and code deploys wait for a human. A yellow form pops up; nothing risky happens until you answer.
